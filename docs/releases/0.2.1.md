# LovestGateWay v0.2.1

- 修复 Mihomo 在线更新在宿主 DNS 返回 FakeIP 时连接 GitHub 超时的问题。官方下载优先通过网关内部出站，未运行网关时可直连；保留 TLS、官方来源、CPU 型号和 SHA256 校验。
- 新增一键安装与升级脚本：自动获取正式发行包、核对清单及内部文件后进入中文向导，支持无人值守参数。
- 正式版本改用简短编号，构建提交和上游基线保存在 `release-manifest.json`。
- 精简 README 和安装说明，日常使用与维护参考分开导航。

在实际 Debian 实例验证了官方更新信息、amd64-v3 核心下载及摘要；在线安装完整流程通过隔离目录安装验证。自动测试覆盖网络回退、TLS/HTTP 错误、校验失败、归档路径和发布保护。

Mihomo v1/v2/v3 是 CPU 指令集型号。GitHub 限流时按提示等待冷却，已有核心继续运行；更换核心仍按原有安装、验收和回退流程处理。

安装与升级见 [使用指南](https://github.com/Lovest20018/LovestGateWay/blob/main/docs/debian-deployment.md)。
