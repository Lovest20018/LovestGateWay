# LovestGateWay v0.2.6

- 代理设置独立显示用户名、密码、固定的 HTTP / SOCKS5 端口和连接说明；保存后回显用户名，密码继续隐藏，可单独更换密码。
- 概览新增近 1 小时 / 24 小时的历史流量、CPU、内存、观测连接失败率及默认出口检测延迟。采集使用持久分页游标和独立分钟汇总，避免反复读取旧记录；采样缺口、计数器归零与出站核心重启不会产生虚假流量。
- Debian 控制循环减少重复哈希和正常状态日志，默认每 10 分钟输出摘要，异常、恢复和实际故障切换仍即时记录。详细日志可使用 `PPGW_LOG_VERBOSE=1` 开启。
- 订阅候选经过校验，且完整 YAML 与运行配置一致时跳过不必要的重启；无法确认等价或配置实质变化时继续使用事务重启与回退。
- 增加真实 PPsub CLI 的合成故障切换验证，覆盖健康节点不切换、指定组故障切换、全部失败保留选择。升级保留已有组模式，不会自动替用户开启故障转移。

历史采集仍需在“设置 → 维护与 API”中开启；指标从开启后积累，不补造过去数据。连接失败率仅代表已观测 TCP 建连结果，不等同于网站成功率；检测延迟读取已有近期检测，采集本身不主动测速。

在“设置 → 维护与 API”升级，或重新运行[一键安装命令](https://github.com/Lovest20018/LovestGateWay#一键安装)。升级保留配置，重启期间短暂断连；任务完成后刷新页面。
