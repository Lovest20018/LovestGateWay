# LovestGateWay v0.2.8

- 订阅与策略编辑加强规则目标、规则集引用和格式校验。错误会指向对应字段或规则，Mihomo 子规则循环引用会显示专用提示。规则页支持查看测试命中的节点组、定位规则及清除定位。
- 符合热重载条件的静态策略修改可保留现有 TCP 连接。节点组改名后继承仍然有效的节点选择和锁定，加载失败时恢复原策略并核对服务。
- 实时日志支持查看近期记录，短暂断线后会补读。续传超出缓存范围时会提示缺口。
- 手机端显示当前页名，设置和诊断预览支持滚动、键盘取消和焦点返回。区域检测开启隐藏 IP 后，详情、复制和导出也会脱敏。
- 大连接列表减少对其他 Web 请求的影响，静态资源支持压缩和缓存校验。登录失败限流按 IPv6 `/64` 网段归并，Rust 依赖包含安全更新。

在「设置 → 维护与 API → LovestGateWay 更新」中升级，或按[安装与升级指南](https://github.com/Lovest20018/LovestGateWay/blob/main/docs/debian-deployment.md)操作。升级沿用现有配置和订阅，服务重启期间转发会短暂中断，完成后刷新页面并重新登录。
