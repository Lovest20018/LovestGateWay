# LovestGateWay v0.2.2

- 新增 Web 网关升级：在“网关设置 → 维护与 API”检查本项目正式版、查看发行说明并确认安装；与 Mihomo 更新分别显示。
- 更新使用独立后台任务，页面断线或刷新后可继续查询同一任务；不会自动重发安装请求。
- 安装前校验发行包摘要、内部清单、版本及架构；保留配置与启动状态，沿用备份、启动验收和失败恢复流程。
- 延续 v0.2.1 的 GitHub 下载路径修复、一键安装与简化文档。

从没有 Web 更新入口的旧版升级，请先运行 README 中的一键命令。Web 更新只接受本项目较新的 amd64 正式发行版；检查结果有效期为 30 分钟。安装会短暂重启网关。
