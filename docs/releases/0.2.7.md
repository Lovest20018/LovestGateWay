# LovestGateWay v0.2.7

- 定时和手动订阅刷新按运行设置执行 DNS 预解析和本地策略叠加。校验后的生效配置等价时保留运行进程，并记录刷新结果与应用原因。配置确有变化时继续通过事务应用，失败时回滚。
- Web 手动清零和月度自动清零保留活跃 TCP、UDP 连接。清零后的聚合数据只计新流量，实时图表和运行历史识别清零断点。
- 核心连续不可用满 20 秒时，观测采集发出告警。采集恢复时记录中断时长，历史保留采样缺口。
- 观测 API 设置显示服务根地址。HNM 填写根地址，手工查询实例时在根地址后追加 `/api/v1/instance`。

通过「设置 → 维护与 API → LovestGateWay 更新」升级，或按[安装与升级指南](https://github.com/Lovest20018/LovestGateWay/blob/main/docs/debian-deployment.md)操作。升级沿用已有配置、订阅和采集设置。升级重启期间转发会短暂中断，完成后重新登录并刷新页面。
