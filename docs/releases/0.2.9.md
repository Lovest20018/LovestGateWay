# LovestGateWay v0.2.9

- 代理页与规则页为开启故障转移的手动选择组显示「手动 · 故障转移」，保持手动点击切换；顶部模式切换收口为「规则」与「全局」，核心被外部设为直连时提示一键恢复。
- 订阅与策略编辑器收口为原生 LovestSub 流程，节点组支持手动选择、自动测速、智能测速及手动组故障转移勾选，移除易冲突的完整 Clash YAML 在线改写；面板文案与默认导出文件名统一为 `LovestSub` / `lovestsub.json`，保持原有本地配置路径与旧文件导入兼容。
- LovestSub 支持多订阅私有 DoH/DoT 按节点域名隔离生成 Mihomo `proxy-server-nameserver-policy`，安全合并 `base.yaml` 的 DNS 与 `hosts`，并在关闭节点 DNS 预解析时保留扩展引导 DNS。
- 保留订阅中的 `hosts` 域名别名并在节点 `server` 上直接展开为目标域名，同时按协议保留原有 TLS `sni`/`servername`，避免跨订阅解析串台与别名解析失败。

在「设置 → 维护与 API → LovestGateWay 更新」中升级，或按[安装与升级指南](https://github.com/Lovest20018/LovestGateWay/blob/main/docs/debian-deployment.md)操作。升级沿用现有配置、订阅和节点组设置，服务重启期间转发会短暂中断，完成后刷新页面并重新登录。
