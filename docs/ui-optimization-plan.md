| 登录恢复补充 | 设置与订阅原地登录保留草稿；设置、核心维护与网关升级续查原任务，提交中或未确认结果保持操作锁；未知设置任务经只读核对与明确确认后可停止本浏览器追踪；更新核对为空闲后恢复操作；旧会话迟到的 401 不影响新登录，写入不自动重放 |
| 可读性补充 | 手机节点操作保留文字并扩大到 44px；节点名与延迟字号增大，亮色延迟文字加深；概览区分速率与累计量，图表显示采样时间范围与数值刻度，进程细节按需展开 |

## 逐页布局

各页统一主标题、工具栏、状态反馈和表格操作。手机端工具栏自然换行，宽表在内部滚动。保存与应用集中显示，次要操作按需展开，错误和待恢复事务保持可见。

| 分栏 | 布局 |
| --- | --- |
| 概览 | 运行摘要单独成行，流量、CPU 与内存、网络接口分区。等待曲线时缩小空白 |
| 代理 | 组头显示当前节点、数量和测速。组内筛选与测速设置按需展开 |
| 规则 | 独立搜索，规则测试、GEO 与订阅数据管理可展开。列设置可隐藏统计详情并记忆选择 |
| 连接 | 活动与已关闭分开查看。工具栏提供搜索、列设置和关闭操作，关闭全部需确认 |
| 流量 | 累计与速率摘要统一呈现。工具栏提供视图、时间和搜索，清空操作需确认 |
| 分布 | 节点统计和客户端、域名排行分区，支持流量、持续时间和连接数排序 |
| 日志 | 集中显示来源与核心最低级别，各来源有独立搜索、暂停和条数设置 |
| 区域 | 默认展开基础、AI、全球服务。筛选时展开匹配组，清除时恢复原样 |
| 订阅 | 每类默认展开首行，新增或复制时自动展开，保存区显示修改状态 |
| 设置 | 运行核对显示摘要，过期或失败时自动展开详情 |
| 诊断 | 优先显示当前状态和故障，异常服务自动展开，集中展示备份、恢复预览和任务进度 |

## 验证

合成浏览器测试覆盖桌面、320/375px 手机、亮暗主题、焦点与草稿、排序筛选、导出、认证恢复、确认及未知结果核对。复杂编辑覆盖原生 PPsub 和完整配置两种模式、60 个节点组与 1000 个候选。

认证恢复、完整设置与核心维护、网关升级及主要页面浏览器回归已接入 Debian CI，先通过浏览器作业再进入打包，验证范围见[测试说明](testing.md)。自动测试、隔离安装和真实客户端业务分别记录；真实客户端透明业务和公网 IPv6 仍按环境独立验收，整体项目状态见[项目状态](optimization-roadmap.md)。
