# 页面布局检查与后续整理

2026-11-07。检查范围为 11 个分栏及设置、订阅、诊断的子页签。依据可维护页面源码和桌面、320/375px 手机合成页面；未以模拟数据推断真实业务访问成功。

本轮已实施侧栏收窄、两行品牌、分组缩进、折叠记忆、单按钮外观轮换和“退出”简写。以下为页面内容区的后续建议，尚未实施。

## 共用布局

- 页面只保留一个主标题。左侧放标题和简短状态，右侧放常用操作；搜索与筛选单独成行，不与版本、运行模式、危险操作混排。
- 页签位于标题下方，工具栏位于当前页签内部。统一输入框和按钮高度、间距、圆角、标题字号及内容区起始位置。
- 统计摘要使用同一种紧凑样式；同类数字单位和累计/实时含义保持原样。空数据、等待采样和功能未开启使用紧凑的明确说明。
- 保存、应用等主要动作集中在当前编辑区；导入、导出、列设置等次要动作收进工具菜单。清空、关闭全部和恢复配置保留清晰的范围与确认，不与刷新并排强调。
- 每页只设一个主要反馈位置。常态运行信息简短展示，详细解释可展开；未确认结果、待恢复任务和错误原因保持可见。
- 手机按“标题 → 页签 → 搜索/筛选 → 内容”换行，不把桌面长工具栏缩成碎片。表格保留横向滚动和列设置，不压缩到文字难读。

## 实施与验收边界

先统一标题、工具栏、反馈和表格工具区，再整理代理、规则、连接和订阅；不同时大改统计含义、默认筛选、导出内容或自动刷新频率。

每批对照原行为验证：焦点与草稿保留、排序和筛选、分页、隐藏规则、节点选择与测速、列设置、鉴权恢复、操作确认和未知结果核对、手机抽屉与主题。暂不为追求整齐而删除运行提示、凭据保护、恢复入口或已有功能。

公网 IPv6 目前缺少环境条件，独立记录为未执行；隔离 IPv6 本地转发测试不替代公网验收。
