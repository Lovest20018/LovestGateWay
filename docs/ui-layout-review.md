# 页面布局整理记录

2026-11-07。范围为 11 个分栏及设置、订阅、诊断的子页签。侧栏和本页列出的内容区整理均已实施，保留现有主题与业务含义。

## 共用布局

- 统一主标题、常用操作、筛选工具栏、状态反馈和表格工具区；消除观测页面重复的内边距。
- 统一按钮、输入框、卡片、统计摘要的尺寸和间距。手机工具栏自然换行，表格在内部横向滚动。
- 保存与应用集中显示；导出、列设置等次要操作归入对应工具区，危险操作仍保留原有范围与确认。
- 常态说明可以展开，错误、未确认结果和待恢复事务保持可见。

| 诊断 | 当前状态与故障优先；服务详情按需展开，异常服务自动展开；备份、恢复预览和任务进度保持连续可见 |

## 验收边界

本轮使用本地合成页面验证桌面、320/375px 手机与亮暗主题，覆盖焦点和草稿、排序/筛选/分页、节点选择与测速、列设置、导出、鉴权恢复、确认及未知结果核对。订阅还覆盖 PPsub 与完整配置两种模式的干净表单行操作，以及 60 个组、1000 个候选节点的复杂编辑。

合成数据不代表真实订阅或外部服务可用。41 的安装包一致性、隔离升级和原生服务验收另存于本地私有记录；不向 GitHub 提交凭据、主机快照或运行日志。本轮不修改采集含义、默认过滤、导出范围或自动刷新频率。

客户端透明业务链与公网 IPv6 仍需对应客户端及网络条件，不能由本轮页面检查推导通过。
